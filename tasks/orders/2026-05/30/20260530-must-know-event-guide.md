# 2026-05-30 Moras 필독안내 페이지 추가

## Socratic Dialogue

- Question: 이벤트 하루 전 참가자가 가장 먼저 봐야 할 페이지 이름은 무엇이 적절한가?
- AI Recommendation: `필독안내`를 사용한다. 짧고, 기존 `진행방법`보다 우선순위가 높다는 의미가 분명하다.
- User Answer: 왼쪽 첫 메뉴에 마지막으로 꼭 알아야 할 부분을 간략히 정리하는 페이지를 원함.
- Decision: `/must-know` 페이지를 만들고 헤더 첫 메뉴명을 `필독안내`로 노출한다.

## Scope

- 새 필독 안내 페이지를 추가한다.
- 기존 안내성 페이지 헤더의 가장 왼쪽에 `필독안내` 링크를 추가한다.
- 페이지에는 썸/친목 차이, 참가자 할 일, 일정 프로세스, 룰렛 이벤트 조건을 간결하게 담는다.
- 하윤 대신 빛나, 밀라 캐릭터 이름을 사용한다.
- 안내문과 CTA 잠금 해제 시간이 어긋나지 않도록 이벤트 오픈 시각을 `2026-05-31T16:00:00Z`로 맞춘다.

## Out of Scope

- 매칭 알고리즘, 신청 폼, 투표 로직 변경.
- 기존 테스트 데이터 삭제.
- 매칭/투표/룰렛 운영 시간 로직 변경.
