# 작업 지시서: Moras MVP 인증 제거 반영

작성일: 2026-05-18 20:16:38 CDT  
작업 유형: 문서 정리  
LLMWiki: 임시 비활성

## 배경

사용자가 Moras MVP에는 인증이 들어가지 않으며, 누구나 접속할 수 있게 할 것이라고 결정했다. 기존 계획 문서에는 Supabase Auth, 관리자 패스코드, 관리자 접근 제한 등이 남아 있어 MVP 방향과 맞지 않는다.

## 목표

Moras 아키텍처 및 계획 문서에서 인증/로그인/패스코드 기반 접근 제어를 제거하고, 누구나 접속 가능한 MVP 전제로 정리한다.

## 수정 대상

- `docs/project-plan.md`
- `docs/product/moras-product-brief.md`

## 작업 내용

1. 운영자 화면에서 관리자 로그인/접근 제한 항목 제거
2. 권장 아키텍처에서 인증 항목 제거
3. 관리자 접근 섹션을 “인증 없는 공개 MVP 운영 방식”으로 변경
4. 보안/개인정보 원칙을 인증 없는 구조에 맞춰 최소 수집, 민감정보 표시 최소화 중심으로 변경
5. 개발 단계, 미정 사항, 리스크에서 인증 전제 제거
6. 제품 브리프의 미정 사항에서 관리자 인증 방식 제거

## 완료 기준

- `docs/project-plan.md`에서 Supabase Auth/관리자 패스코드 권장 문구가 제거된다.
- `docs/product/moras-product-brief.md`에서 관리자 인증 방식이 미정 사항에서 제거된다.
- 인증이 없다는 결정과 개인정보 최소화 리스크가 문서에 함께 반영된다.
- 완료 보고서에 검증 결과와 `LLMWiki: 임시 비활성`을 남긴다.
