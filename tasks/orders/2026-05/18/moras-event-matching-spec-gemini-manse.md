# 작업 지시서: Moras 이벤트 매칭 스펙 정리

작성일: 2026-05-18 20:34:05 CDT  
작업 유형: 제품/아키텍처 스펙 정리  
LLMWiki: 임시 비활성

## 배경

사용자가 Moras MVP를 “쓸데없는 페이지 없이 Netlify에 꼭 필요한 기능만 올려 이벤트를 진행하는 웹앱”으로 정의했다.

주요 결정:

- 인증 없음
- 참가자는 DB에 미리 입력된 대상 중 드롭다운으로 본인을 선택
- MBTI는 직접 입력
- 사주는 만세력 결과를 활용
- Gemini API로 MBTI/사주 기반 상호 점수와 매칭 이유를 생성
- 모든 참가자 입력 완료 후 운영자가 일괄 매칭 실행
- 성비가 맞지 않으면 적은 쪽 기준으로 1:1 강제 매칭
- 평균 점수 공개, 1등 하이라이트
- 상세 페이지에서 매칭 이유 확인
- 남녀 각각 비밀 투표

## 목표

현재 계획 문서에 위 내용을 반영하고, 별도의 이벤트 플로우 스펙 문서를 작성한다.

## 완료 기준

- Gemini API 사용 방식이 스펙에 반영된다.
- 만세력 처리 방식이 “포스텔러 공개 API 미확인, 캡처 업로드 + Gemini Vision 추출 우선”으로 정리된다.
- 매칭 알고리즘이 상호 점수 평균 기반 1:1 강제 매칭으로 정리된다.
- 상세 페이지와 비밀 투표 흐름이 반영된다.
- LLMWiki는 실행하지 않고 `LLMWiki: 임시 비활성`으로 보고한다.
