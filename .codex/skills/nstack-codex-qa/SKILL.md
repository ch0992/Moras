# NStack Codex QA

## Workflow

1. Identify changed or planned behavior.
2. Group checks by user flow, admin flow, data flow, and deployment risk.
3. Define core, standard, and edge-case scenarios.
4. Include privacy and consent checks for participant data.
5. Map each scenario to an automated or manual verification method.
