# NStack Codex NOffice

## Workflow

1. Collect completed and in-progress task reports.
2. Translate technical details into operational impact.
3. Reference GitHub issues/PRs when available.
4. Save to `docs/noffice/YYYY-MM-DD.md` when requested.

## Style

- Korean by default.
- Avoid code snippets.
- Focus on purpose, outcome, risk, and next action.
