# NStack Codex Investigate

## Workflow

1. Reproduce or clearly describe the symptom.
2. Narrow affected files, docs, service, or workflow stage.
3. Trace the execution or documentation path.
4. State the root cause in one sentence.
5. Propose the smallest fix and verification method.
