# NStack Codex Retro

## Workflow

1. Collect recent work orders, reports, and commits. LLMWiki entries are temporarily excluded until integration is re-enabled.
2. Identify Keep, Problem, Try items.
3. Separate product findings from NStack process findings.
4. Propose rule or skill changes only for repeated patterns or high-risk failures.
5. Save retro output under `docs/retro/YYYYMMDD-HHMMSS/retro.md` when requested or useful.
