## 목적

`@fullstackfamily/manseryeok` 계산 결과를 포스텔러 결과와 비교해 Moras MVP에서 서버 측 만세력 계산 라이브러리로 사용할 수 있는지 1차 판단한다.

## 실행 명령

운영자 생년월일시는 저장소에 기록하지 않고 실행 시 인자로만 전달한다.

```bash
npm run manse:validate -- --date YYYY-MM-DD --time HH:mm --calendar solar --timezone Asia/Seoul
```

음력 입력을 검증할 때는 다음 형식을 사용한다.

```bash
npm run manse:validate -- --date YYYY-MM-DD --time HH:mm --calendar lunar --timezone Asia/Seoul
```

## 출생지/경도 확인 메모

`@fullstackfamily/manseryeok`의 `calculateSaju`는 진태양시 보정을 지원한다. 이 보정을 켜면 경도에 따라 시주가 달라질 수 있다.

현재 운영자 샘플 시간은 15:20이라 시주 경계에 가깝다. 같은 양력 입력 기준으로 다음 차이가 확인됐다.

| 조건 | 보정 시간 | 시주 |
|---|---:|---|
| 경도 127, 시간 보정 true | 14:48 | 신미 |
| 경도 127, 시간 보정 false | 보정 없음 | 임신 |
| 경도 129.5, 시간 보정 true | 14:58 | 신미 |
| 경도 130, 시간 보정 true | 15:00 | 임신 |

제품 결정: 출생지가 국내외 모두 열릴 수 있어 MVP 입력에서 태어난 도시/경도는 제외한다. 따라서 Moras MVP의 1차 계산은 기록된 출생시간을 그대로 사용하고, 진태양시 보정은 기본 비활성화한다.

주의: 이 정책은 입력을 단순하게 만들지만, 경계 시간대의 시주가 전통 진태양시 방식과 다를 수 있다. 포스텔러 비교도 같은 기준인지 확인해야 한다.

포스텔러 캡처 기준으로는 진태양시 보정이 적용된 결과와 시주가 일치한다.

| 비교 항목 | Moras 보정 true | 포스텔러 캡처 | 메모 |
|---|---|---|---|
| 시주 | 신미 | 신미 | 일치 |
| 12운성 | 연 태 / 월 관대 / 일 쇠 / 시 묘 | 연 태 / 월 관대 / 일 쇠 / 시 묘 | 일치 |
| 12신살 | 연 장성살 / 월 화개살 / 일 천살 / 시 월살 | 연 년살 / 월 화개살 / 일 천살 / 시 월살 | 생년 칸만 기준 차이 확인 필요 |
