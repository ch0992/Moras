# Moras 제품 브리프

## 한 줄 정의

Moras는 오픈채팅 이벤트 참가자가 웹앱에 접속해 MBTI와 사주 정보를 입력하고, MBTI 성향 점수와 명리학 기반 기질 점수를 조합해 가장 잘 맞는 남녀를 매칭하는 이벤트용 웹 애플리케이션이다.

## 이름의 의미

Moras는 MBTI 기반 성향 분석과 사주, 운명, 기질 해석의 느낌을 함께 담기 위해 선택한 이름이다.

| 요소 | 의미 |
|---|---|
| M | MBTI, Mind, Match |
| Oracle | 사람의 성향과 관계 흐름을 해석하는 상징 |
| S | Saju, Sync, Soul |

## 기획 의도

현재 오픈채팅에서 진행되는 이벤트를 웹 애플리케이션 기반으로 전환한다.
참가자는 별도 설명을 오래 읽지 않고 접속, 입력, 제출을 완료할 수 있어야 하며, 운영자는 이벤트 참가자들의 정보를 기반으로 매칭 결과를 산출할 수 있어야 한다.

핵심 재미는 "나와 가장 잘 맞는 사람은 누구인가?"에 있다. MBTI의 익숙함과 사주의 신비감을 결합해, 가볍지만 몰입감 있는 이벤트 경험을 만든다.

또한 Moras는 NStack을 실제 제품 개발에 적용해 검증하는 파일럿 애플리케이션이다. 제품을 완성하는 과정에서 NStack의 지시서, 검증, 보고, 지식화 흐름이 실전에서도 유효한지 함께 확인한다.

## 핵심 이벤트 흐름

1. 참가자가 Moras 웹앱에 접속한다.
2. 성별, 닉네임, 연락 또는 식별 정보, MBTI, 생년월일/시간 등 사주 계산에 필요한 정보를 입력한다.
3. 시스템이 참가자 프로필을 저장한다.
4. 이벤트 운영자는 남녀 참가자 간 궁합 점수를 계산한다.
5. MBTI 점수와 사주 기반 점수를 조합해 가장 잘 맞는 매칭 후보를 산출한다.
6. 운영자가 최종 결과를 확인하고 이벤트 방식에 맞게 발표하거나 안내한다.

## MVP 범위

### 참가자 화면

- 이벤트 입장 화면
- 참가자 정보 입력 폼
- MBTI 선택
- 사주 입력용 생년월일, 출생시간, 양력/음력 선택
- 개인정보 및 이벤트 이용 동의
- 제출 완료 화면

### 운영자 화면

- 참가자 목록
- 성별/제출 상태 필터
- 매칭 점수 계산 실행
- 남녀 매칭 후보 리스트
- 참가자별 상세 점수 breakdown

### 매칭 엔진

- MBTI 궁합 점수
- 사주 기반 기질 점수
- 최종 점수 산식
- 동일 참가자 중복 매칭 방지 옵션
- 운영자 수동 조정 여지

## 초기 점수 모델

정확한 명리학 해석 엔진은 별도 고도화 대상으로 둔다. MVP에서는 설명 가능한 간단한 점수 모델을 먼저 구현한다.

| 구성 요소 | 가중치 | 설명 |
|---|---:|---|
| MBTI 궁합 | 50% | 외향/내향, 판단/인식 등 지표 조합 기반 |
| 사주 기질 | 40% | 오행/일간/계절성 등 단순화된 기질 점수 |
| 이벤트 보정 | 10% | 나이 차이, 입력 완성도, 운영자 보정 등 |

## NStack 파일럿 관점

Moras 개발 과정에서는 제품 기능뿐 아니라 NStack 자체도 검증한다.

- 신규 프로젝트 초기화가 재현 가능한지 확인
- Supabase, Netlify, GitHub, LLMWiki 연결 흐름 검증
- 각 작업의 지시서와 보고서 작성 품질 확인
- SwarmVault 검색이 다음 작업에 실제로 도움이 되는지 확인
- 개발 중 발견한 NStack 개선점을 회고와 LLMWiki에 기록

## 중요한 제품 원칙

- 참가자 경험은 짧고 직관적이어야 한다.
- 결과는 "재미있는 이벤트"로 느껴져야 하며, 결정론적 운명 판정처럼 표현하지 않는다.
- 사주 해석은 민감할 수 있으므로 과도한 단정 표현을 피한다.
- 개인정보 입력 항목은 최소화하고, 운영 목적을 명확히 고지한다.
- 운영자가 결과를 검토하고 조정할 수 있어야 한다.

## 아직 결정해야 할 것

- 웹앱 기술 스택
- 데이터 저장 방식
- 관리자 인증 방식
- 실제 사주 계산 정확도 수준
- 참가자에게 결과를 직접 보여줄지, 운영자만 볼지
- 오픈채팅 이벤트 운영 방식과 결과 발표 방식
